# Velonna rings, bracelets and pendants catalogue

This folder contains the completed pricing workbook and the Shopify product-import data for 50 lab-grown diamond designs.

The calculation uses the rates established in the supplied workbook:

- 925 silver: ₹250/g
- 9K gold: ₹5,790/g
- 14K gold: ₹9,003/g
- 18K gold: ₹11,576/g
- Lab-grown diamonds: ₹42,000/ct
- Making charge: ₹1,850/g
- GST: 3%

`velonna-rings-bracelets-pendants-import.csv` contains 600 variants: four metal purities multiplied by three metal colours for each of the 50 designs. The final rate is used as the Shopify selling price; the pre-GST subtotal is stored as cost per item.

The supplied workbook does not contain physical stock quantities. These are set up as made-to-order variants without Shopify inventory tracking.
